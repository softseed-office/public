よくある質問

書いた考えはどこに保存されますか？

この端末の中だけに保存されます。サーバーには送らず、開発者も見ることはできません。アプリがインターネットを使うのは次の場合だけで、どの場合も書いた考えは送りません。

  • 新しい今日の一文と、バージョン1.2.0からは「みんなの考えの森」に表示する数字をダウンロードするとき
  • プライバシーポリシーやこのサポートページを開くとき
  • アプリでエラーが起きたときにエラー情報を送るとき
  • バージョン1.1.0からは、「利用状況の統計を送る」がオンなら、アプリを開いた日や流れを保存したかなどの利用状況の統計を送るとき
  • バージョン1.1.0からは、設定 → お問い合わせからお問い合わせを送るとき
  • バージョン1.2.0からは、サポーターのサブスクリプションを購入するときや登録状況を確認するとき（App Store・Google Playと通信します）

利用状況の統計は設定 → 利用状況の統計を送るでいつでもオフにできます。

機種変更したら記録を移せますか？

同じ種類の端末に機種変更する場合は、端末のバックアップで記録と設定が一緒に移ります。

  • iPhone：新しいiPhoneの設定でクイックスタートまたはiCloudバックアップから復元を選ぶと戻ります。コンピュータのバックアップから復元することもできます。アプリだけを削除して再インストールしても、記録は戻りません。
  • Android：端末のGoogleバックアップがオンなら、同じGoogleアカウントで新しい端末を設定したとき、またはアプリを再インストールしたときに、最後のバックアップが戻ります。

バックアップはふつう1日に1回ほど行われるため、最後のバックアップ以降に書いた考えは含まれないことがあります。機種変更の前に、バックアップがオンになっているか確認してください（iPhone：設定アプリ → [ユーザ名] → iCloud → iCloudバックアップ / Android：設定で「バックアップ」を検索 — メニュー名は端末によって少し異なります）。

バージョン1.2.0からは、設定 → 記録を書き出すで記録をひとつのファイルにまとめ、新しい端末の設定 → 記録を取り込むで取り込めます。iPhoneとAndroidのあいだでも使えます。もう一度取り込むには「取り込み用（JSON）」の形式で書き出してください。「閲覧用（テキスト）」は読むためだけのものです。

複数の端末で一緒に使う同期機能はまだありません。アプリにはアカウントがないため、記録は端末とそのバックアップ、そして自分で書き出したファイルにだけあります。

毎日の通知が届きません。

アプリの設定 → 毎日の通知がオンになっているか、端末で通知が許可されているかを確認してください（iPhone：設定アプリ → 通知 → A Thought／Android：設定 → アプリ → A Thought → 通知）。その日にもう考えを書いていたら、その日は通知しません。

つくった画像が写真に保存されません。

iPhoneでは設定アプリ → アプリ → A Thought → 写真で「追加のみ」を許可してください。Android 10以降は許可なしで保存され、Android 8〜9では保存時に表示されるストレージへのアクセスを許可してください。アプリは写真を追加するだけで、端末の写真を読み取ることはありません。ただし、バージョン1.2.0からは、カレンダー画像の背景として自分で選んだ写真1枚は、カレンダーを描くときにのみ使い、保存したり送ったりはしません。

記録を削除したいです。

考えの流れの画面の「その他」メニューからひとつずつ削除するか、設定 → 記録をすべて削除でまとめて削除できます。削除した記録は元に戻せません。

サポーターのサブスクリプションを解約したいです。

サポーターのサブスクリプション（バージョン1.2.0から）は、登録したストアのアカウントで解約します。アプリの設定 → 応援してかざる → サブスクリプションを管理をタップすると、ストアのサブスクリプション管理画面が開きます。ストアから直接開くこともできます。

  • iPhone：設定アプリ → [ユーザ名] → サブスクリプションで「A Thought」を選んで解約します。
  • Android：Playストア → プロフィールアイコン → お支払いと定期購入 → 定期購入で「A Thought」を選んで解約します（メニュー名は少し異なることがあります）。

解約しても、すでにお支払いいただいた期間が終わるまではサポーターの機能を使えます。期間が終わると、保存した画像や動画はそのまま残り、選んでいたサポーターの背景はデフォルトに戻ります。書くことと記録はそのまま使えます。アプリを削除しただけでは解約されないため、必ずストアで解約してください。返金はApp Store・Google Playにご依頼ください。

機種変更や再インストールのあと、サポーターが使えません。

サブスクリプションはストアのアカウントにあります。登録したときと同じApple AccountまたはGoogleアカウントでサインインしている端末なら、アプリを開いたときに自動で確認されます。使えないときは、アプリの設定 → 応援してかざる → 購入を復元をタップしてください。インターネット接続が必要です。

「復元できる購入はありません」と表示されたら、端末のストアのアカウントが登録したアカウントと同じか、サブスクリプションの期間が終わっていないかを、ストアのサブスクリプション管理で確認してください。サブスクリプションはストアごとに別々のため、iPhoneで登録したものをAndroidで使うこと（またはその逆）はできません。アプリ自体にアカウントはなく、確認するのはストアのアカウントだけです。

プライバシー

A Thoughtは書いた考えを収集しません。集めるのは、アプリの不具合を直すためのエラー情報、バージョン1.1.0からは「利用状況の統計を送る」がオンの場合にアプリを良くするための利用状況の統計、そしてバージョン1.1.0からは設定 → お問い合わせから自分で送ったお問い合わせだけです。バージョン1.2.0から購入できるサポーターのサブスクリプションの決済はApp Store・Google Playが処理し、運営者は決済情報を受け取りません。くわしくはプライバシーポリシーをご覧ください。
