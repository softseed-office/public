# 피아노 체커 / Piano Checker 공개 페이지

App Store·Play 제출과 앱의 정보 화면에서 여는 페이지. 정적 파일만 있고 외부 의존 없음.

| 파일 | 용도 | 쓰는 곳 |
|---|---|---|
| `privacy.html` | 개인정보처리방침 (한국어) | App Store Connect·Play Console 개인정보 처리방침 URL, 앱의 정보 화면 (`privacyUrl`) |
| `support.html` | 지원·문의 (한국어) | App Store Connect 지원 URL |

- 앱 저장소: `softseed-office/piano-checker` (Issue #35).
- 앱은 한국어만 있어서 문서도 한국어만 있다. 다른 언어로 내게 되면 문서도 함께 더한다.
- 앱이 새 정보를 다루게 되면 앱 업데이트 전에 개인정보처리방침부터 고친다.
- **출시 전에 다시 볼 것**: 방침 4번(인앱 구매)은 기획에 따라 미리 적었다. 결제 기능(piano-checker #31)이 들어가면 실제 동작과 다시 대조하고, 지원 페이지에 구매·구매 복원 질문을 더한다.
- 아이콘은 앱 저장소의 `tools/app_icon/icon.png` 를 180px 로 줄인 것이다.
